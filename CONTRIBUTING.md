# Contributing

[Home](README.md) · [Stato](STATUS.md) · [Ipotesi](HYPOTHESES.md) · [Esperimenti](EXPERIMENTS.md) · [Metodo](REPRODUCIBILITY.md) · [Documenti](reports/README.md) · [Roadmap](ROADMAP.md)

Please open an issue with a precise hypothesis, corpus version, segmentation, split and falsifiable prediction. Include positive/negative controls and preserve failed calibrations in the record. Do not promote an exploratory p-value to a decipherment claim.

Code changes: use a branch and pull request. Keep raw copyrighted sources and private correspondence out of commits. Recompute SHA256 for newly added derived assets. Run `python scripts/check_publication.py` before publishing.
