Methods & tests · for statisticians and replicators

How we tried
not to fool ourselves.

Undeciphered scripts attract pattern-finding. The safeguards below are the core of the project: held-out pages, matched samples, null models, positive controls, and a public record of the tests that failed.

Design principles

Five rules for every experiment.

RULE 1

Test on unseen pages

Models are fitted on some pages and scored on others. Splits are by page, never by word, so a model cannot memorise the test text.

RULE 2

Compare like with like

Corpora are matched for sample size and word-length distribution before any comparison, because both change entropy estimates.

RULE 3

Prove the test can succeed

Each method is first run on a positive control where the answer is known: enciphered Latin, synthetic grammars. If it fails there, its failure on the Voynich means nothing.

RULE 4

State the null

Every “above chance” claim names its shuffle: within line, within page, by position and length bin, by bifolio group.

RULE 5

Keep the failures

Superseded and failed analyses stay in the repository with their results, marked as such. Scope every negative result to a model, a dataset and a coding.

How glyphs are counted TRANSCRIPTION

We use a working inventory of 23 graphic units: 17 single EVA letters (a d e f g i k l m n o p q r s t y) and 6 connected clusters (ch sh ckh cth cph cfh), matched greedily. This covers 99.96% of legible paragraph text in ZL3b. Alternative readings are resolved by taking the first variant (817 cases); 209 illegible markers are excluded. The inventory is a convention for counting. It is not a claim that these are 23 letters.

Facts that make naive letter readings risky: q is word-initial 99.5% of the time and followed by o 98.0% of the time; n follows i 98.0% of the time and ends the word 99.0% of the time. Whether qo and iin are single units is unresolved.

Uncertainty

What our intervals mean, and what they do not.

The min–max range across overlapping page splits describes sensitivity to the split. It is not a confidence interval.

Page-bootstrap intervals resample test pages and keep the fitted models fixed. They are conditional on those models and on this corpus.

Pages in the same quire are not independent, and the two Voynich transcriptions share sources. The split replications reuse pages and are not independent books.

No correction for multiple comparisons has been applied. The project is exploratory: treat every p-value and interval as a guide for the next confirmatory test, not as a conclusion.

Why statistics alone cannot prove a text is meaningless

Without restricting the family of encodings, any finite string C can be matched to any plaintext P of the same length by choosing the key K = C − P modulo the alphabet size. This is an identifiability argument, not a historical claim that a one-time pad was used. A negative result is only meaningful once we say which encodings, languages and segmentations it excludes.

Reproduce

Rerun everything in five commands.

Python 3.10+ with NumPy (Pillow only for the OCR image panel). The substitution attack also needs a C++17 compiler.

git clone https://github.com/fabiofurini/voynich-seraphinianus-lab
cd voynich-seraphinianus-lab
pip install -r requirements.txt
python scripts/fetch_data.py                 # downloads sources, verifies SHA-256
python scripts/reproduce.py --suite matched  # or: affixes, hierarchy, calibration,
                                             #     multiscale, boundary, substitution
